# Como contribuir

Obrigado pelo interesse no Mundo dos Macacos!

1. Cria uma branch com um nome claro, por exemplo `feature/nova-especie`.
2. Faz alterações pequenas e focadas.
3. Executa `npm test` antes de abrir um pull request.
4. Descreve no PR o problema, a solução e como foi testada.
5. Para novas espécies, inclui nome comum, nome científico, continente, habitat, alimentação, estado de conservação e uma curiosidade verificável.
6. Usa fontes credíveis e indica-as na documentação.

Todas as alterações devem ser revistas antes de serem integradas na branch principal.
