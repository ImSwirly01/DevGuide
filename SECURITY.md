# Política de segurança

Este projeto é educativo e não recolhe dados pessoais nem utiliza serviços de autenticação.

## Reportar um problema

Não publiques vulnerabilidades exploráveis em issues públicas. Contacta o responsável pelo repositório através dos canais privados disponibilizados no perfil GitHub.

## Boas práticas

- Não introduzir tokens, palavras-passe ou dados pessoais no repositório.
- Manter dependências e Actions atualizadas.
- Rever alterações antes de as integrar na branch principal.
